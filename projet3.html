Projet – Installation d'un environnement de développement

Description

Ce projet consistait à installer et configurer un environnement de développement complet dans une machine virtuelle. Il fallait installer Debian 13 avec l'interface graphique KDE/Plasma, puis y configurer les outils essentiels : un JDK, Git, et l'IDE IntelliJ IDEA Community selon trois méthodes d'installation différentes (archive, snap, flatpak).

Compétences

Administration système Linux, gestion de machines virtuelles, installation de packages Debian, utilisation du terminal (shell), vérification d'intégrité via empreinte SHA-512, gestion des droits administrateur (sudo), comparaison de méthodes d'installation de logiciels.

Objectifs

Savoir installer un système d'exploitation Linux depuis une image ISO. Configurer un environnement de développement Java opérationnel. Comprendre et comparer trois méthodes d'installation d'un même logiciel (archive, snap, flatpak) et leurs implications en termes d'espace disque et de gestion des paquets.

Travail individuel

Projet réalisé individuellement. Chaque étape (création de la machine virtuelle, installation de l'OS, configuration des outils) était documentée par des captures d'écran précises montrant les commandes exécutées, les versions des logiciels installés et l'état du système. Les captures ont été déposées sur la plateforme Chamilo dans les délais impartis (3 heures).

Techniques et savoirs faire acquis

Installation et vérification d'une image ISO Debian via empreinte SHA-512. Configuration d'une machine virtuelle avec résolution 1440×900 sous KDE/Plasma. Installation de Git et d'un JDK via les packages Debian. Installation d'IntelliJ IDEA Community en trois façons : par archive tar.gz, par snap et par flatpak. Comparaison des méthodes d'installation et analyse de l'espace disque consommé.
